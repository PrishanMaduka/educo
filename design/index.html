Quad design prototypes

Interactive designs for the school platform. The admin web app covers the six core modules for staff. The parent app follows the iParent model: one login for every child, alerts, results, payments and messages. Both use the same colours and type, and both have light and dark themes.

Admin web app

Dashboard, admissions pipeline, CRM, student records, attendance, LMS, fees and accounting. Press Ctrl K to search.

Open admin app →

Parent mobile app

Face ID unlock, child switcher, attendance calendar, results, timetable, homework, card payments, trips, messages and push alerts.

Open parent app →

Modules in the admin prototype

Pre-admission & enrolment

Drag-and-drop pipeline, applicant drawer with document checklist, three-step application form.

CRM

Scored leads, source filters, campaigns, enquiry forms and a parent inbox that replies to the app.

Student information

Directory in table or card view, full profile with attendance heatmap, results, fees and conduct, live register.

Learning management

Course spaces, assignment tracking, weighted gradebook that recalculates as you type, weekly timetable.

Fees & invoicing

Invoice list by status, invoice preview, record payment, bulk billing run, fee structures and receipts.

Finance & accounting

Income vs expenditure, journal entries with a debit/credit balance check, chart of accounts, budgets.

All names, figures and records are sample data for a fictional school.
